# 🚗 Car Price Prediction App

A Machine Learning web application built with **Streamlit** to predict car prices using multiple regression models.

## 🌐 Live Demo

Try the application here:

👉 https://app-car-price-model-1.streamlit.app/

## 📌 Project Overview

This project implements a complete machine learning pipeline for car price prediction.

The application compares three regression models:

- Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor

Users can:
- Enter vehicle characteristics
- Predict estimated car prices
- Compare model performances
- Visualize evaluation metrics

## 🧠 Machine Learning Models

| Model | RMSE | R² Score |
|---|---|---|
| RidgeCV | 8395.48 | 0.823 |
| Random Forest | 4399.24 | 0.951 |
| Gradient Boosting | 4240.44 | 0.955 |
